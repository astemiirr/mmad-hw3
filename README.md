# Подборка хороших вин

Приложение на Streamlit для классификации вин по 12 физико-химическим признакам. Хорошее вино — экспертная оценка не ниже 7. Используется сохранённый пайплайн StandardScaler + LogisticRegression. Порог выбран по F1 на валидации; обучение внутри приложения не выполняется.

## Запуск

Проверено с Python **3.13.3**. Для Streamlit Community Cloud используется Python **3.13**.

Из папки приложения:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

В Windows вместо `source .venv/bin/activate` используется `.venv\Scripts\activate`.

## Возможности

Четыре вкладки: оценка одного вина, метрики на тестовой выборке, пакетное предсказание по CSV и коэффициенты модели. Порог в боковой панели общий для всех вкладок. Пример входного CSV можно скачать в приложении. Столбец `is_red`: 0 — белое вино, 1 — красное. Отсутствующие столбцы и некорректные значения сопровождаются сообщением об ошибке.

## Кэширование

Модель загружается через `st.cache_resource`: на сервере хранится один объект модели. Для таблицы и массивов вероятностей используется `st.cache_data`, возвращающий копии данных. Аргумент `_model` исключён из хеширования. Изменение порога не требует повторного вычисления вероятностей тестовых объектов.

Без декоратора `joblib.load` читал бы модель с диска при каждом действии пользователя. После замены модели приложение нужно перезапустить, чтобы сбросить кэш.
